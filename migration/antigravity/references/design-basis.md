# Design basis and limits

These roles divide claim examination, mechanism tracing, evidence review, modality calibration, relational editing, and optional satire into separate responsibilities. Personal source attribution, private archive links and archive-specific entry references have been omitted from this public distribution.

| Responsibility | Role | Boundary |
|---|---|---|
| Establish the exact claim and scope | Claim Examiner | Include strongest reading and disconfirming conditions |
| Explain operations and dependencies | Mechanism Tracer | Distinguish hypotheses from inspected implementation |
| Check support and counter-evidence | Evidence Auditor | Apply the same burden to a critique |
| Calibrate certainty | Modality Calibrator | Preserve warranted certainty without automatic hedging |
| Inspect relationship and register | Relational Editor | No unsupported motive or mental-state attribution |
| Produce optional satire | Satirical Reframer | Explicit request; factual claims remain evidence-bound |

SFL guides expression and analysis; it supplies neither execution guarantees nor empirical certainty. The roles are capabilities, not personality simulations.
